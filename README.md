# מדפסת הבית

אפליקציית אנדרואיד לניהול HP Laser MFP 137fnw ברשת המקומית: סריקה ישירה אל
הטלפון, מצב המדפסת והטונר, והדפסת קבצים.

## מה היא עושה

- **סריקה** ממשטח הזכוכית או ממזין הדפים, בצבע / גווני אפור / שחור-לבן, ב-100
  או 200 או 300 dpi, כ-PDF או JPEG. התוצאה נשמרת בתיקיית ההורדות ואפשר לפתוח,
  לשתף או להדפיס אותה מיד.
- **מצב** — דגם, פנויה או מדפיסה, אחוז טונר, אורך התור, מצב הסורק והאם יש דפים
  במזין, מספר סידורי וגרסת קושחה.
- **הדפסה** — בחירת PDF או תמונה והעברה לחלון ההדפסה של אנדרואיד.
- **חיפוש ברשת** — מוצא את המדפסת לפי השם שהיא משדרת ב-mDNS, כך שאתחול ראוטר
  שמשנה לה כתובת לא שובר את האפליקציה.

## איך זה עובד מתחת לפני השטח

שני פרוטוקולים פתוחים, בלי שום תוכנה של היצרן:

- **eSCL** (AirScan / Mopria Scan) לסריקה. שליחת POST ל-`/eSCL/ScanJobs`, קריאת
  כתובת העבודה מכותרת `Location`, ואז `GET <job>/NextDocument` עד שהמדפסת מפסיקה
  למסור עמודים.
- **IPP** על פורט 631 למצב ולטונר, בבקשת `Get-Printer-Attributes` אחת. הבקשה
  נבנית כבייטים בקוד ולא דרך ספרייה חיצונית.

שתי מלכודות שכדאי להכיר לפני שנוגעים בקוד:

1. מסמך היכולות קורא למזין הדפים `Adf`, אבל `pwg:InputSource` מקבל רק `Platen`,
   `Feeder` או `Camera`. שליחת `Adf` גורמת למדפסת לסרוק את הזכוכית במקום, להחזיר
   דף לבן, ולדווח על הצלחה.
2. המדפסת לא מקבלת PDF להדפסה — רק QPDL, PCLm ו-URF. לכן ההדפסה עוברת דרך
   מנגנון ההדפסה של אנדרואיד, שממיר את הקובץ, ולא בשליחה ישירה לפורט 9100.

ה-HTTPS של המדפסת פתוח אבל הקושחה מ-2019 ולקוחות מודרניים מסרבים ללחיצת היד
שלה, כך שכל התקשורת היא HTTP. בשל כך `network_security_config.xml` מתיר תעבורה
לא מוצפנת. האפליקציה לא פונה לשום שרת מחוץ לרשת הביתית.

## בנייה

הבנייה רצה ב-GitHub Actions ואין צורך ב-Android Studio. כל דחיפה ל-`main`
בונה APK, מעלה אותו כ-artifact, ומפרסמת אותו בשם `latest` תחת Releases.

להתקנה בטלפון: להוריד את ה-APK מה-Release האחרון ולאשר התקנה ממקור לא מזוהה.

מקומית, למי שיש לו Android SDK:

```
gradle assembleDebug
```

## דרישות

מינימום אנדרואיד 10 (API 29), כי השמירה לתיקיית ההורדות נעשית דרך MediaStore.
